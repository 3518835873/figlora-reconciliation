# 数据字典

## 概述

所有数据文件使用 UTF-8 BOM 编码（utf-8-sig），CSV 格式，逗号分隔，首行为列标题。日期格式为 ISO 8601 (YYYY-MM-DD)，金额单位为人民币元（¥）。

---

## 1. artist_list.csv — 艺术家主数据

| 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 艺术家编码 | 文本 | 唯一标识，格式 AR-NNN | AR-001 |
| 艺术家姓名 | 文本 | 中文姓名或艺名 | 林小喵 |
| 身份类型 | 文本 | 艺术家背景 | 独立潮玩设计师 |
| 关联SKU | 文本 | 逗号分隔的 SKU 编码列表 | BC-01,BC-07 |
| 分成比例 | 百分比 | 销售收入分成比例（6%-10%） | 8% |
| 结算方式 | 文本 | 版税结算方式 | 销售后结算 / 预付+结算 |
